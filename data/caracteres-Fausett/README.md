# Caracteres Fausett - Exemplo

Esse é o conjunto de dados usado como exemplo em sala de aula. Esse conjunto também pode ser usado por você para testar seu código, uma vez que o aprendizado deste conjunto pode ser feito com uma rede de uma camada. A rede MLP também pode ser testada com esse conjunto a fim de verificar a dinâmica de treinamento. Este NÃO é o conjunto que deverá ser explorado no trabalho que será entregue na disciplina. Esse é apenas um exemplo para "aquecimento" do seu raciocínio.
