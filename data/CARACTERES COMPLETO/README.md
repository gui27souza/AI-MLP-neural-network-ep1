# Caracteres Completo

- A base de dados possui 1326 caracteres com resolução de 10x12 pixels.

- Os últimos 130 exemplos devem pertencer à base de dados de teste.

- Descrição dos arquivos:
    - X_png.zip: Zip que contém as fotos no formato .png (1326 fotos)
    - X.txt: Arquivo .txt que possui os valores dos pixels escritos em linha (120 valores/linha)
    - Y_letra.txt: Cada linha contém o caractere correspondente à cada exemplo da base (1326 linhas)
